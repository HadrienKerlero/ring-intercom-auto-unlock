# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment, personal attacks and trolling are not tolerated.

Report unacceptable behavior to the maintainer via the contact listed in [SECURITY.md](SECURITY.md).
